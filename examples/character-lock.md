# 人物一致性锁定示例

多次出图要固定同一组人物时，把人物设定写进提示词而不是写进技能全局配置。
下面是从真实文章插图项目里沉淀的写法，按需改写，不要原样套用。

## 写法

放在 `--extra` 或 prompt-spec 的 `extra` 字段里：

```
人物设定（务必遵守）：女儿是一位三十多岁的成年女性；父亲是一位六七十岁、头发花白的年迈患者。
两人的服装、发型与年龄在整组图里保持一致。
```

## 为什么需要

生图模型默认倾向把人物画年轻、画成通用面孔。不写死设定时，一组 3 张图里人物年龄和脸会漂移。

## 注意事项

- 只描述可见特征（年龄、发色、服装），不写性格与背景故事。
- 一组图共用同一段设定，逐字不改。
- 需要跨会话复现时，把这段存到 prompt-spec 里用 `--prompt-spec` 调用，而不是每次手打。
- 这段属于**项目级内容**，不属于技能默认行为，因此放在 examples 而不是配置里。
